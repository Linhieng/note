## bash

在 window terminal 中使用 pwsh7 通过 ssh 连接服务器（bash）。

- ctrl + u 清空光标到行首
- ctrl + k 清空光标到行尾
- ctrl + w 删除光标前的 unix word（具体地讲，是 whitespace-separated unix word，即以空格或制表符作为边界）
- alt + d 删除光标后的 word（具体地讲，是 Readline word，即以空格制表符和`\/-_.:`作为边界。Readline 其实是 GNU 的一个库，用来实现这些快捷键的功能，而快捷键的习惯，其实是源自 Emacs 编辑程序）
- alt + backspace 删除光标前的 word
- ctrl + l 翻页
- ctrl + a 等同 home
- ctrl + e 等同 end
- ctrl + b 等同 ← ArrowLeft
- ctrl + f 等同 → ArrowRight
- ctrl + p 等同 ↑ ArrowUp
- ctrl + n 等同 ↓ ArrowDown
